## What changed since run 477's build

* **Wanda's rug, the last of the four dotted seams** (the object audit's class 6, the owner's #73; engine `1334a605`, the
  building tools only): a room's floor decal hangs a skirt down to the floor along the GBA's line of sight where the
  floor laid under it is another colour, and the rug a piece hides runs a texel under the rug round it. Over every
  indoor place (329, two cameras, Linux): no new artifact; lines of the ground's colour at floor edges now the floor's
  own (the Pokemon Centers, the Marts, the houses).
* **The Ranking Hall's front** (V44; engine `179093a5`, the building tools only): its shading band stays the wall's face
  instead of two windows set back with sills on the ground.
* **A move's own picture of a Pokemon from the sprite pack** (S7; engine `a3e7b65b`, PC only): Role Play's silhouette and
  the runner of Snatch's stolen move, Hyperspace Hole, Hyperspace Fury and Skitter Smack drawn from the battle sprite pack
  when there is one. **This package carries no pack** (the packaging log: `HAVE_SPRITES: false`), so its battles draw the
  GBA's sprites, as before.
* **Smooth slopes, a preview off by default** (the owner's #71 C; engine `3821d2cb`, the 3D view only): with
  `PKMN_DIORAMA_SMOOTH_SLOPES=1` set before the game starts, the bumpy and muddy slopes are smooth ramps and a sprite
  crossing one stands on it. Unset, nothing changes (the four-pixel steps, #71 B).

Play is unchanged: the 3D changes only draw; collision, warps and events are the GBA game's.
