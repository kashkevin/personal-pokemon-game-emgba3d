MAJOR PROJECT DIRECTIVE — MIGRATE TO NATIVE PC + EMERALD 3DS GRAPHICS
PROJECT: POKÉMON EMERALD MULTIPLAYER — WINDOWS EDITION
We are officially changing the technical direction of our existing Pokémon Emerald Multiplayer project.
This is a migration of our current game, NOT a new project and NOT a restart.
Our new objective is to transform everything we have already built into a genuine standalone Windows PC game, while adopting the enhanced graphics and visual rendering style of Pokémon Emerald 3DS Dual Screen.
We want to preserve all existing gameplay, systems, progress, and development work.
Do not discard, recreate unnecessarily, or overwrite functioning systems.
1. NEW PRIMARY TARGET
Our finished game must be:
A native Windows PC game that runs directly through a standalone `.exe`, without requiring a GBA emulator.
We no longer want the final game to run underneath mGBA.
Current architecture:

* Pokémon Emerald ROM built from pokeemerald-expansion
* Customized mGBA emulator
* Windows launcher
* Lua multiplayer bridge
* Python companion
* Python multiplayer host/server

Target architecture:

* Native Windows executable
* Pokémon Emerald gameplay engine running directly on PC
* Existing gameplay systems preserved
* Existing Python multiplayer server preserved wherever compatible
* Native networking bridge replacing the emulator-specific Lua bridge
* Enhanced 3D-style overworld renderer
* Single-screen PC interface
* Keyboard/controller support
* Persistent player saves

The goal is to eliminate the emulator dependency without sacrificing our existing game.
