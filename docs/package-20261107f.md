## What changed since run 380's build

The app's `bfc288e` (the host), `6af8b76` (the launcher), `b55a361` (Setup) and `a5b2075` (the quick start); the engine
and the GBA ROM unchanged. What a player meets:

* **One launcher at a time on a player's files (KNOWN_ISSUES MS-220, Medium)** (app `6af8b76`, the launcher only):
  nothing stopped a second launcher on the same player's files. A second click on the EmeraldTogether icon while the
  first was open, or still opening, started another menu on the same characters and worlds, where a second game of the
  same character could run beside the first's, and each launcher's record of the characters was written over the
  other's. The launcher now holds a lock among the player's files while it runs (`launcher.lock` in
  `%LOCALAPPDATA%\PokemonPrivate\launcher`); a second one shows "EmeraldTogether is already open on this PC. Its window
  may be behind other windows or minimized on the taskbar." and ends. Windows lets go of the lock when the launcher
  ends, however it ends (closed, crashed, or ended in Task Manager); a lock file that cannot be used lets the launcher
  start as before.
* **The Battle Tower and the championships ignore changes made to the host PC's clock (KNOWN_ISSUES MS-219, Low)**
  (app `bfc288e`, the host only): the Tower's solo battles and the eight-place championships' computer matches are
  settled by time on the host (a command no game started is void after two minutes; a started battle that never
  reports is a loss after a day), and those times were read from the host PC's clock, so a change made to it counted as
  time passed: the clock set a day forward during a friend's Tower battle counted it as a loss (the win the game then
  reported was refused); set a day back, a dead command kept the Tower closed a day longer. They are now measured on a
  clock that leaves out changes made to the PC's clock while the host runs (time asleep still counts); the rules
  themselves (two minutes, a day) are unchanged.
* **Save in the game before an update** (app `b55a361` and `a5b2075`): Setup, run over an installed EmeraldTogether,
  now says on its first page to save in the game first: it closes a running EmeraldTogether, and a game it closes
  keeps only what was saved, as when its window is closed. The quick start says the same, and that EmeraldTogether
  opens once.
