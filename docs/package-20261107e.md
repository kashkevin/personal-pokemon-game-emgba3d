## What changed since run 373's build

The engine's `7b9f6bfa` (PC only) and the app's `e554184` and `b77cb84` (the launcher); the GBA ROM unchanged. What a
player meets:

* **A Windows user name with an accent or another script (KNOWN_ISSUES MS-217, High)** (engine `7b9f6bfa`, PC only):
  the launcher keeps a player's files under their Windows user folder and gives the game their paths; for a user name
  such as José, Zoë or 测试 the games of every earlier build could not open them (the C library read the paths in the
  PC's code page) and started on an empty save, without their link to the launcher and their settings. Both games now
  carry an application manifest that makes Windows read their paths as UTF-8 (Windows 10 version 1903 and later; an
  earlier Windows keeps the fault).
* **The launcher's file moves wait out an antivirus's or the indexer's brief hold** (app `e554184`): enrollment's moves
  of the earlier saves, the game settings file the launcher writes and a deleted character's or world's folder retry
  for up to two seconds on Windows when another program holds the file for a moment, as the save paths already did;
  after that the same message as before.
* **A character's earlier versions kept when the PC's clock goes back (MS-218, Medium)** (app `b77cb84`): Characters >
  Restore an earlier version keeps a character's 40 newest earlier saves, and with the PC's clock set back (by hand, as
  players do for the game's time-based events, or a flat clock battery) each new version, and a copy made with Back up
  now, was deleted as soon as it was written. A new version is now never named before the newest kept, so the newest
  stay; the current save was never touched.
