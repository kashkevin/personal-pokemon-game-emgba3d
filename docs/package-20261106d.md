meets:

  `0f666958`, `deed5de9`, `568d1fb1`).
* **The Battle Dome's ends curve back with its drum in 3D (V45)** (engine `084b02e0`).
* **The Battle Dome's tourney tree no longer reads past its state while it is set up (MS-203)** (engine `816390b8`).
* **The UBSan build's findings** (engine `961ec505`, `bc038550`, `d93170ef`): a script moving an object not on the map
  wrote past the object table (MS-204); a level-100 exp bar read past the experience table (MS-204); the time of day's

## Not in this build

Engine commits after `ae3889a7`, each PC only (the GBA ROM unchanged), for the full run after this one:

* `3a2fe777` (MS-209): a Pokemon's low vertical shake divided by zero at its table's end; the release builds never reach
  that division (their code checks the end first): nothing a player sees.
* `f22f8a54` (MS-210): with every sprite palette slot taken, the Pokemon Center's Poke Ball glow, dowsing, the PokeNav's
  headers and the slot machine wrote past the palette buffers; the palette writers now refuse it. A real Pokemon Center
  with every slot taken was not seen; in this build treat a crowded Pokemon Center as able to write past them.
* `d5142431`, `fc8626c1` (MS-211): a text printer, the field's name box and the PokeNav's row clearing for a window that is
  not there drew through a pointer past the window table (MS-206's kind; no path in play seen).
* `70cf7d18` (MS-212): a save file write that failed (a full disk, the file held by another program such as an
  antivirus, no write access) was not tried again nor told: the game went on as saved. Now it is tried again after 1
  second, up to every 30, and five times as the game closes; the reason is logged and the window's title says so. In
  this build a failed write waits for the next save: keep the folder `%LOCALAPPDATA%\PokemonPrivate` writable and out of
  a sync tool's lock.
