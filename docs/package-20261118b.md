## What changed since run 479's build

* **The verification audit's launcher fixes** (app `834999a`; each found by the audit's real launchers and games, each
  with a unit test that fails without it, each rechecked in real launchers on Linux; KNOWN_ISSUES):
  * MS-254: the session window no longer keeps "Saving..." over every later status (a full disk's message among them).
  * MS-255: a save waits 15 s for each answer of the host (5 s before), so a stall the connection survives no longer
    fails the save.
  * MS-256: the trade banners' texts ("Trade cancelled: no change.") and a PLAYERS notice a letter too long.
  * MS-257: another program on a world's port is named as such ("close the running host, or the other program using
    that port"), and the reason reaches the menu.
  * MS-258: the Battle Tower Duo's pages after Accept and Ready start on a name row, so a second or third press no
    longer opens the team page, takes a Pokemon out or undoes Ready.
  * NU-1's gap: a character setup ended just after reaching the field no longer leaves every later setup of that place
    refused.
  * NU-3's gaps: a replaced invite code says at once that the host did not accept it (it waited out the time limit), and
    another world's code says "That is not the world from your invite" (it said the certificate had expired).
* **"Allow Internet connections?" at world creation** explains the current setup (KNOWN_ISSUES MS-253; app `40b38a1`).
* **The prompts in each controller's own buttons** (KNOWN_ISSUES MS-252's polish; engine `25eb56eb`, PC only): a
  PlayStation pad's symbols, a Switch Pro's letters, the Xbox letters for the rest. The Windows self-test job now also
  runs the controller checks in the 3D game (`keybinds-3d`; app `abbbd01`).
* The audit's tooling (the proofs' new scenarios, `launcher_real_checks.py`, `save_retry_real_proof.py`): scripts the
  package does not carry.
* **Not in this build**: MS-260 (PokeNav > World's player rows keep whole words; app `ca87db1`, after this run began):
  it is in the next full run's.
