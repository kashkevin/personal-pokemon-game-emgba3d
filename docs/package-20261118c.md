## What changed since run 482's build

* **No false warning when the game is closed right after a save** (KNOWN_ISSUES MS-259; app `707a651`): at a normal
  close the game's link to its companion ends a moment before the game's exit is seen, and the launcher showed "This
  save needs recovery..." or "Connection to the host was lost..." for a moment before "Game closed... saved (as of your
  last save)". Nothing was saving and the save was in the world; the warning was false. The status now waits for the
  exit (3 s at most) when the link ends with nothing saving; a game that keeps running after that, or exits otherwise,
  is still told. Shown with real launchers on Linux before and after (6 of 8 closes before, none after; a friend's
  rejoins 5 of 6 before, none after) and on Windows (below).
* **PokeNav > World keeps whole words** (KNOWN_ISSUES MS-260; app `ca87db1`): a long name and place no longer ends
  mid-word ("Friend Fl - LITTLEROOT TO" is now "Friend Fl - LITTLEROOT").
* The audit's proof tooling (the real-launcher checks' `close-after-save` scenarios, the walking-stall and full-queue
  proofs of MS-123 and MS-124): scripts the package does not carry.
