## What changed since run 359's build

Engine `ae3889a7` to `2e851759` (every game change PC only, the GBA ROM unchanged); the app's code unchanged. What a
player meets:

* **A save the game could not write is tried again, and said (MS-212, Medium, save integrity)** (engine `70cf7d18`):
  when writing the save file failed (a full disk, the file held by another program such as an antivirus or a sync tool,
  no write access), the old save stayed whole but the game went on as saved: neither later frames nor closing the game
  tried again, and only the log said so, so closing the game before the next save that worked lost that progress. Now a
  failed write is tried again after 1 second, then up to every 30 seconds, and five more times as the game closes; the
  reason goes to the log and the crash report's errors.log; the window's title reads "the save file could not be
  written: trying again" until a write works (not seen in full screen); the 3D pause menu's save shows the failure, then
  "saved" when a later try writes it.
* **No palette write past the palette buffers (MS-210, Medium)** (engine `f22f8a54`): with every sprite palette slot
  taken, the Pokemon Center's Poke Ball glow, dowsing, the PokeNav's headers and the slot machine wrote 16 colours far
  past the buffers; the palette writers now refuse a range past them.
* **No drawing into a window that is not there (MS-211, Medium)** (engines `d5142431`, `fc8626c1`): a text printer, the
  field's name box and the PokeNav's row clearing for window 255 drew through a pointer past the window table (MS-206's
  kind, which closed the Windows 3D game; no path in play seen); they now refuse it.
* MS-209 (engine `3a2fe777`): a Pokemon's low vertical shake divided by zero at its table's end in the sanitizer build;
  the release builds never reach that division: nothing a player sees.
* The shiny check's keep walks (engine `2e851759`, a test script, not the game): from Route 101's path below Oldale
  Town instead of through its grass, where a wandering overworld Pokemon stopped run 363's walk three tries out of three.
