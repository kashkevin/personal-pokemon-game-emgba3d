## What changed since run 389's build

The app's `310e470` (the launcher only) and the engine's `72518ddf` (the 3D view's rules only); the GBA ROM unchanged.
What a player meets:

* **A game ends with the launcher that started it, however the launcher ends (KNOWN_ISSUES MS-221, Medium)** (app
  `310e470`, the launcher only): the launcher holds what its game needs to save into its world (the companion's
  connection, the lease on the character's save file), but a game it had started did not end when the launcher ended
  without closing it (a crash, or End task on EmeraldTogether.exe in Task Manager's Details). The game played on
  disconnected, nothing it saved could reach its world, and EmeraldTogether started again could open a second game of
  the same character on the same save file beside it. Each game the launcher starts (the play session's, the world
  registration's, the New Game's) now ends with the launcher: on Windows the game joins a job object the launcher holds,
  which Windows ends with its processes when the launcher ends, however it ends. The game keeps what it last saved, as
  when its window is closed. The quick start's "If something else goes wrong" says: "EmeraldTogether closed
  unexpectedly, or was ended in Task Manager, while you played: the game window closes with it. Start EmeraldTogether
  again; your character has what was last saved."
* **Safari Zone South's white rails and east plateau in the 3D view (KNOWN_ISSUES MS-222, Medium)** (engine `72518ddf`,
  the 3D view's rules only; the owner's report of 2026-11-09 with a screenshot): north of the entrance, the white rails
  on posts that run over the valley from the raised enclosure west of it to the raised plateau east of it lay on the
  valley floor like benches, with a flight of white stairs at their west end, and the plateau on the valley's level (its
  cliffs thin walls on flat ground). The enclosure, the rails and the plateau now stand a level over the valley, the
  rails a boardwalk with the valley open under it, and the path north climbs the two levels from the seam to the
  plateau. Only Safari Zone South's 3D records change (all 441 layouts compared); the Classic 2D game is unchanged.
