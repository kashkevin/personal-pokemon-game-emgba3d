## What changed since run 297's build

* **Saves after a power cut** (KNOWN_ISSUES MS-196): the native game flushes its save file's data to the disk before
  the rename that replaces the old save (`FlushFileBuffers` on Windows), so a power cut or a system crash in the
  seconds after a save leaves the old save or the new one whole, never an empty or garbage file. A disk that cannot
  flush (some network shares) still saves as before and the log says so once.
* **A world's files after a refused store** (MS-197): a world's shared world, friendship or wager store refused as it
  opened (another world's file beside this one) kept its file open until Python's garbage collector came round, and
  the world server kept the stores it had already opened, so on Windows the world's files stayed locked until the
  launcher closed. Each now closes as it is refused.
* **The Classic 2D Slot Machine's payout table** (MS-84): SELECT shows the PC game's payouts, not the GBA's.
* Test builds only (not in the packaged games): the gameplay check runs the reset-guarded static encounters offline
  (MS-156), and its plan runner sets the plan's flags before its warps and finds a Gym Leader's trainer after the
  co-op offer.
