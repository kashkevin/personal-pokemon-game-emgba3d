* **The night music table read only for its own tracks (MS-213, Low)** (engine `6d46a38d`): at night by the game's
  clock (18:00-04:00), a warp to a map that plays no music (the Battle Pyramid, Birth Island, the Cave of Origin's B1F,

  played a music number found there instead of the silence. In the builds read (the local Windows games, the GBA ROM)

  run of the whole gameplay plan at night.
