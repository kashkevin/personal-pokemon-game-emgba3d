## What changed since run 478's build

* **The bumpy slopes smooth** (the owner's #71, "smooth slopes for bumpy slopes only"; engine `eb81c028`, the 3D view
  only): the Acro Bike's bumpy slopes are smooth ramps by default and a sprite crossing one stands on it; the muddy
  slopes keep their four-pixel steps (unchanged until verified, as decided). Play is the GBA's: the 3D view only draws.
* **With a battle sprite pack, Spinda keeps its own spots** (#76; engine `98c795d2`, PC only): the game's own picture
  with the spots of each Spinda's personality, as the original (the pack's animation has one pattern for every Spinda).
* **With a battle sprite pack, the pack draws 3D battles only** (#77; engine `98c795d2`, PC only): 2D battles (the
  Classic 2D game, the 3D game's classic view) draw the game's own sprites, which always fit their frame, as the
  original does. **This package carries no pack** (`HAVE_SPRITES: false`): #76 and #77 apply only once a player adds
  one; every battle of this package draws the GBA's sprites, as before.
* **Any controller in the game** (KNOWN_ISSUES MS-252; engine `c7b0d80d`, PC only): a PlayStation, Switch Pro or other
  pad SDL can map now plays the game when no Xbox (XInput) pad is there; an Xbox pad works exactly as before.
* #75 (a tall Pokemon's head behind the foe's lower healthbox in doubles) and #78 (Route 119's Acro Bike rails) were
  kept as the original Emerald draws them: nothing changed for them.
