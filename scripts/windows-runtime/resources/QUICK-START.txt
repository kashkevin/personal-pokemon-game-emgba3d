Emerald Together — private Windows package

Before starting

Extract the complete ZIP and keep EmeraldTogether.exe beside its _internal
folder. Open EmeraldTogether.exe. Python, a compiler and WSL are not needed
on a friend's PC. See README.txt for this package's game-import availability.
An import-disabled preview requires a separately prepared matching installation;
it cannot install the game on a new PC yet.

Packages labeled "Gen6 defaults" use a separate game and rules identity. This
selects engine generation defaults; it is not the completed Gen6 game. Keep
candidate 9 for worlds created with that release. Installing the new game does
not convert or repin an old world or rewrite its Pokemon. Use a new world and
newly prepared characters for this candidate. See RELEASE-LIMITS.txt.

Install your own game once

1. In an import-enabled package, choose "Import my game…" and select your
   matching original Emerald .gba dump or ZIP containing exactly one .gba.
   Archives are read in memory; your original dump/archive is not changed.
2. Wait for "Game installed". The launcher validates the original, patch and
   reconstructed game against this release's exact hashes before publishing
   its private copy. An existing different installation is never overwritten.
3. "Check installed game files" verifies the ROM, manifest and runtime pins
   without starting a game. File verification does not establish gameplay,
   network acceptance or import availability in an import-disabled preview.
4. Every friend's PC repeats this import with their own matching dump and
   the same release package. Never include the game or saves in the shared ZIP.

Create the host world

1. Choose "Set up a world or character…", then "I'm hosting".
2. Enter the host name and up to three friends' names. Choose the numeric
   address friends will reach and the game port before creating the world.
   127.0.0.1 works only on this PC. For friends on your home network, use the
   host PC's local network address. The default game port is 8765.
3. If this release offers native trade effects, explicitly choose the world's
   trade friendship rule. Read the two choices before creating the world;
   setup does not pick one for you, and it becomes permanent for this world.
4. Choose "Create private world". Keep the host world on the host PC.

Upgrade features in an existing same-release world

Close every character, host session and game first. In setup, select the exact
host world on the character tab, then open "Upgrade world features". Select and
approve its trade friendship rule and the backed-up upgrade. The action retains
verified backups, adds supported personal-attempt tracking and initializes
missing older handler values to each species' Gen 6 base while preserving known
values. An already chosen rule cannot be changed here. This does not convert an
older world's game build, resolve unfinished trades/battles or replace saves.
Use it only when this exact installed release supports the displayed upgrade.

Prepare a character on either player's PC

1. A friend chooses "I'm joining a friend" in setup. The host can also use
   "Set up character". Choose "Create a new character…", or select an
   existing original character save that has no multiplayer ownership.
2. For a new character, play ordinary New Game, choose a starter, use the
   game's normal Save menu, then close the game using its title-bar Close.
   The launcher selects the saved character after validating it.
   Follow the starter selector in that exact game build. In a build with the
   eighteen-starter selector, Up/Down or L/R changes region; Left/Right picks
   one of three starters and A previews/confirms it. Older builds differ.
3. A friend on another PC chooses "Export character for host approval…" and
   saves a new .sav copy. Give only that copy to the host yourself; this launcher
   does not send files. The original is preserved. No host world or credentials
   are needed on the friend's PC to prepare and export this character.
4. On the host PC, choose "I am the host", select the character copy, then
   choose the host world and the correct named Host/Friend account. Check the box
   approving that exact character save, then "Approve and open character".
   A source that changes after selection is refused; reselect and review it.
5. Continue in the game to a safe field location outside menus and battles.
   Return to setup and choose "I'm in the world — finish enrollment".
6. Repeat for each friend. Choose each friend's slot and export that friend's
   invitation. Give each person only their own invitation. This preview
   performs initial character approval locally on the host PC. Once enrolled,
   play through Host/Join; do not keep playing or merge the unassigned backup.

Host and join

Host: close setup, choose the world on the Host Game tab, enter this PC's
local address, and choose Host Game. Leave the host running while friends play.

Friend: open the same release, choose Join Game, select your own invitation,
then choose Join Game. "Check connection" checks the invited encrypted
endpoint; it does not log you in or prove an Internet gameplay session.

For Internet hosting, the invitation needs the host's public numeric address.
The host still enters its local address on the Host Game tab, enables
"Allow Internet connections", and forwards the chosen TCP port on the router
to that PC. The current build does not configure the router or firewall.
Separate-PC LAN and outside-network gameplay acceptance are still pending.

Save and finish a session

"Autosave every 5 minutes" is on by default. It waits for a safe field location
outside menus and battles, then saves to the reachable host. You can untick it
in the launcher; that choice is remembered for this character and world on
this PC. Turning it off does not interrupt a save already in progress.

During multiplayer play, return to a safe field location and press "Save now"
in the launcher. Keep the game open until "Character saved to the host" appears.
Save now also works when autosave is off. If the game is busy, leave its menu
or battle and press Save now again. The game's ordinary Save menu does not
confirm that progress reached the host.
After a successful save, close the game through its title-bar Close button,
then close the launcher. Keep private recovery files and follow the displayed
recovery message. If it tells you to keep the game open, leave both windows open.
Closing the game does not itself save progress to the host.

If the host reports an unresolved multiplayer battle, the launcher blocks a
fresh game session. Keep the original game open and retain the recovery files.
Restore the host connection and choose "Recover battle" in every original
player's launcher. The match waits for all of its original players.

If the host service stopped but its original game and launcher are still open,
the host can choose "Restart host service" when that action becomes available.
After it succeeds, the host and every original participant choose "Recover
battle". Restarting the service alone does not resume the match. An exited game
or host application cannot recover its waiting battle through this button.

If the host disconnects during normal exploration or an ordinary save, the
launcher attempts to preserve that exact save locally for rejoining. Wait for
its status before closing. A confirmed preserved save can be reconciled through
Host Game or Join Game after the host returns. An unsafe or uncertain operation
may keep the game held without a completed save; do not close it while the
launcher asks you to keep it open.

If the host disconnects during a trade, keep both original game windows and
launchers open. The surviving host uses "Restart host service" when offered.
Each player then uses "Resolve interrupted trade" and reads its confirmation:
it may cancel an unfinished trade or retain an already committed result. Wait
for the verified message that says closing is safe, then close the game
normally and reopen the same Host/Join identity for recovery and Continue.
If the status remains held or uncertain, retain the game and recovery files.
This does not resume the trade in that same game process or reconstruct an
exited game/whole PC. Do not discard journals or copy a backup over the character.

Trainer Cards and hunt records

Open the launcher's Trainer Card & Players tab and choose Refresh while your
character is connected. Records shows completed 1v1/2v2 results and win streaks,
committed trades and saved party/storage counts. Hunts shows recorded personal
attempts when the world's durable hunt ledger is enabled; attempts do not alter
shiny odds. Records are snapshots, not unsaved live progress. The in-game Players
menu also has Your Trainer Card and connected players' public battle cards.

Host/Join connection details

Choose an invitation to see its host address and port. Copy connection details
copies public support information only. Your friend still needs their own
private invitation file; those details alone do not grant character access.
Controls & Help explains the existing keys and recovery actions.

Default game controls

Arrow keys: move       X: A / confirm        Z: B / back
Enter: Start          Backspace: Select     A / S: L / R

These are the runtime's configured defaults. Physical keyboard, audio and
gamepad acceptance remain pending; automated native-button tests are separate.
The launcher stores private worlds and character/recovery data in the Windows
user's local application-data folder. See RELEASE-LIMITS.txt before sharing
this development preview with friends.
