EmeraldTogether - Quick start

EmeraldTogether is Pokemon Emerald for up to four friends on Windows PCs: play on your own,
host a world on your PC, or join a friend's world. It is a private build for friends who own
Pokemon Emerald. Please do not pass it on to anyone else.


1. Download

Your friend sends you one program file, EmeraldTogether-Setup-<version>.exe, together with
this guide. Save it anywhere, for example in your Downloads folder. That is all you need: no
emulator, no game file, no Python, no GitHub account and no command window.

If your web browser warns that the file is not commonly downloaded, choose to keep it (in Edge:
the "..." next to the download, then Keep, then Keep anyway).


2. Install

Double-click EmeraldTogether-Setup-<version>.exe.

Windows may show a blue box saying "Windows protected your PC". It appears because the installer
is not signed by a company (signing costs money, and this is a private build). Click
"More info", check that the app is EmeraldTogether-Setup-..., then click "Run anyway".

Setup then asks only simple questions. Read the short notes, click Next, and Install. It installs
for your Windows user only and never asks for an administrator password. The program goes to
C:\Users\<your name>\AppData\Local\Programs\EmeraldTogether. Tick "Create a desktop shortcut"
if you want one.

Some antivirus programs distrust new programs that are not signed. If yours warns about
EmeraldTogether or moves one of its files to quarantine, restore the file, allow EmeraldTogether,
and run Setup again (see "Update or repair" below).


3. Start

Open the Start menu and click EmeraldTogether, or use the desktop shortcut. The main menu opens
inside the game's own window: Continue Adventure, New Game, Host Server, Join Server, Settings,
Exit. Use the mouse, or the arrow keys and Enter; Esc goes back; Ctrl+V pastes.

The first time you host, Windows may ask whether EmeraldTogether may use the network. Allow it
on private networks, or friends cannot reach your world.


4. Create your character

The first time you play in a world, the game's normal New Game starts. Choose your name and your
starter Pokemon, then save in the game (START, then SAVE) and close the game window. The game
opens once more by itself: choose CONTINUE. It closes again when your character is registered,
and then your adventure starts. From then on your character loads automatically.


5. Play

Solo. Choose New Game. It creates a private adventure on this PC with a new character, just for
you. Next time, Continue Adventure picks up where you stopped. Starting another New Game never
touches your earlier adventures.

Host World. Choose Host Server, then Create New Server World. Give the world a name, type your
name, and keep the suggested port. For friends at your home (the same router or Wi-Fi), choose
this PC's local network address; for friends elsewhere, also see "Playing over the Internet"
below. Then open your world and choose "Invite codes for friends": every friend has their own
code, copied for you to paste into a message. Send each friend only their own code, privately -
it works like a password. Choose Host This World to start, and keep EmeraldTogether open while
your friends play.

Join Friend. Choose Join Server, then Join New Server, and paste the invite code your friend sent
you (Ctrl+V). EmeraldTogether checks that it can reach your friend's world, saves it in your list
and joins. The first time, you create your character as described above. Next time choose Join
Server and the saved server, or simply Continue Adventure. If your friend's world is not running,
you are told so and can try again; nothing is lost.

Saving. Autosave is on: every 5 minutes, as soon as you stand somewhere safe (not in a menu or a
battle). In a multiplayer world you can also press "Save now" in the small session window next to
the game; wait until it says "Character saved to the host" before you close the game. The game's
own SAVE menu does not, on its own, send your progress to the host. If a message asks you to keep
the game open (for example after a lost connection), leave both windows open and follow it.


6. Where your saves live

Your characters, worlds, saves and settings are kept in your Windows user folder:

    %LOCALAPPDATA%\PokemonPrivate

(Paste that line into the address bar of File Explorer to open it.) They are not inside the
program folder, so repairing, updating or uninstalling EmeraldTogether never removes them.
To make a backup, close EmeraldTogether and copy the whole PokemonPrivate folder somewhere safe.


7. Update or repair

Update: run the newer Setup file your friend sends you. It replaces the program files and keeps
your saves, characters and worlds.

Repair: if EmeraldTogether says a game file is missing or changed, or it will not start, run the
same Setup file again. It puts back every program file. Settings, Game files checks the installed
files without starting anything.

Uninstall: Windows Settings, Apps, EmeraldTogether, Uninstall. Your saves stay in
%LOCALAPPDATA%\PokemonPrivate; delete that folder yourself only if you really want them gone.


Playing over the Internet

Friends at your home join with this PC's local address (Server Information in your world shows
it). For friends elsewhere, the host types the public address in the world's network settings and
turns on Internet access, and the host's router must forward the world's TCP port to the host's
PC. This build does not change your router or firewall settings for you. Server Information says
what is and is not set up.


Default game controls

Arrow keys: move       X: A / confirm        Z: B / back
Enter: Start          Backspace: Select     A / S: L / R

Settings in the main menu lets you change the keys, the graphics (3D or Classic 2D), the display
and the sound. A game controller's D-pad, A and B should work in the menu (not yet tested with
a real controller).


If something else goes wrong

* The menu window does not open: EmeraldTogether opens its earlier launcher window instead, with
  the same worlds and characters.
* A battle or trade was interrupted: keep the game open and follow the message in the session
  window (Recover battle, Resolve interrupted trade). An unfinished trade is cancelled and a finished
  one is kept; nothing is guessed.
* Read RELEASE-LIMITS.txt (in the program folder) for what this build is and what is not finished.
