EmeraldTogether - Quick start

EmeraldTogether is Pokemon Emerald for up to four friends on Windows PCs: play on your own,
host a world on your PC, or join a friend's world. It is a private build for friends who own
Pokemon Emerald. Please do not pass it on to anyone else.


1. Download

Your friend sends you one program file, EmeraldTogether-Setup-<version>.exe, together with
this guide. Save it anywhere, for example in your Downloads folder. That is all you need: no
emulator, no game file, no Python, no GitHub account and no command window.

If your web browser warns that the file is not commonly downloaded, choose to keep it (in Edge:
the "..." next to the download, then Keep, then Keep anyway).


2. Install

Double-click EmeraldTogether-Setup-<version>.exe.

Windows may show a blue box saying "Windows protected your PC". It appears because the installer
is not signed by a company (signing costs money, and this is a private build). Click
"More info", check that the app is EmeraldTogether-Setup-..., then click "Run anyway".

Setup then asks only simple questions. Read the short notes, click Next, and Install. It installs
for your Windows user only and never asks for an administrator password. The program goes to
C:\Users\<your name>\AppData\Local\Programs\EmeraldTogether. Tick "Create a desktop shortcut"
if you want one.

Some antivirus programs distrust new programs that are not signed. If yours warns about
EmeraldTogether or moves one of its files to quarantine, restore the file, allow EmeraldTogether,
and run Setup again (see "Update or repair" below).


3. Start

Open the Start menu and click EmeraldTogether, or use the desktop shortcut. The main menu opens
inside the game's own window: Continue Adventure, Solo, Host World, Join Friend, Characters,
Settings, Exit. Use the mouse, or the arrow keys and Enter; Esc goes back; Ctrl+V pastes.

The first time you host, Windows may ask whether EmeraldTogether may use the network. Allow it,
or friends cannot reach your world.


4. Create your character (once)

You have one character, and it goes everywhere with you: Solo, your own worlds with friends,
and your friends' worlds. Its Pokemon, levels, items, money and story progress go with it.

The first time you choose Solo, Host World or Join Friend (or Characters, Create), EmeraldTogether
offers to create it. The game opens on a New Game ("Creating your character" is shown in the
corner): choose your name, look and starter Pokemon, play until you can save, save in the game
(START, then SAVE) and close the game window. Your character is ready.

The first time your character enters a world (a new Solo world, your hosted world, or a friend's
world), the game opens once on your character: choose CONTINUE. It closes by itself when the world
has saved your character, and your adventure starts. When you come back to a world after playing
somewhere else, the same thing happens once, so your newest progress comes with you. Your earlier
save in that world is kept beside it, never deleted.

Characters lets you rename your character, back it up, restore an earlier save, create another
character and choose which one plays. Deleting a character moves its folder aside; nothing is
destroyed.


5. Play

Solo. Choose Solo, then New world (or one of your worlds). A Solo world is on this PC only. Next
time, Continue Adventure picks up where you stopped.

Host World. Choose Host World, then Create a new world (or one of your worlds). Give the world a
name and keep the suggested port. Open the world and choose "Invite codes for friends": every
friend has their own code, copied for you to paste into a message. Send each friend only their
own code, privately - it works like a password. Choose "Host this world now" to start, and keep
EmeraldTogether open while your friends play. The small session window shows whether your world
is running, whether the router accepted the automatic setup, and how many friends are connected
through a relay, if you use one.

Join Friend. Choose Join Friend, then "Join with an invite code", and paste the code your friend
sent you (Ctrl+V). EmeraldTogether checks that it reaches your friend's world (the right world,
the same game version) before anything starts, saves it in your list and brings your character in.
Next time choose Join Friend and the saved server, or simply Continue Adventure. If your friend's
world cannot be reached, EmeraldTogether tells you why in plain words and what each of you can do,
with "Try again" and "Edit the address"; nothing is created or reset. It never starts a Solo game
instead.

Saving. Autosave is on: every 5 minutes, as soon as you stand somewhere safe (not in a menu or a
battle). In a world you can also press "Save now" in the small session window next to the game;
wait until it says the character was saved before you close the game. When the game closes, your
character's latest save is the world's, so it goes on with you to the next world.


6. Where your saves live

Your characters, worlds, saves and settings are kept in your Windows user folder:

    %LOCALAPPDATA%\PokemonPrivate

(Paste that line into the address bar of File Explorer to open it.) They are not inside the
program folder, so repairing, updating or uninstalling EmeraldTogether never removes them.
To make a backup, close EmeraldTogether and copy the whole PokemonPrivate folder somewhere safe.


7. Update or repair

Update: run the newer Setup file your friend sends you. It replaces the program files and keeps
your saves, characters and worlds.

Repair: if EmeraldTogether says a game file is missing or changed, or it will not start, run the
same Setup file again. It puts back every program file. Settings, Game files checks the installed
files without starting anything.

Uninstall: Windows Settings, Apps, EmeraldTogether, Uninstall. Your saves stay in
%LOCALAPPDATA%\PokemonPrivate; delete that folder yourself only if you really want them gone.


Playing over the Internet

Friends on your Wi-Fi join with your local address (it is in the invite code). For friends
elsewhere there are three ways; HOSTING.txt in the program folder explains each one step by step:

* Port forwarding: turn on Internet access in the world's Network settings. The game asks your
  router to forward the port (automatic router setup, UPnP or NAT-PMP). Many routers allow it;
  some do not, and then you forward the port yourself in the router's settings. It cannot work if
  your Internet provider shares one address between homes (CGNAT).
* Tailscale (free for personal use): install it on both PCs and join the same Tailscale network;
  then choose your Tailscale address (100.x.y.z) in Network settings, Listen on.
* A relay: someone you trust runs EmeraldTogether.exe --relay-server on a PC or small server
  with one reachable port; the host sets its address in Network settings, Relay, and makes new
  invite codes. The relay only passes encrypted traffic. EmeraldTogether does not provide a
  public relay.


Default game controls

Arrow keys: move       X: A / confirm        Z: B / back
Enter: Start          Backspace: Select     A / S: L / R

Settings in the main menu lets you change the keys, the graphics (3D or Classic 2D), the display
and the sound. A game controller's D-pad, A and B should work in the menu (not yet tested with
a real controller).


If something else goes wrong

* A friend cannot connect: the screen they see names the reason (nothing hosted at that address,
  the router does not forward the port, a firewall, a different game version, a different world)
  and what each of you can do. HOSTING.txt has the details.
* The menu window does not open: EmeraldTogether opens its earlier launcher window instead, with
  the same worlds and characters.
* A battle or trade was interrupted: keep the game open and follow the message in the session
  window (Recover battle, Resolve interrupted trade). An unfinished trade is cancelled and a finished
  one is kept; nothing is guessed.
* Something went wrong in the menu: it says so in plain words; the details for whoever helps you are
  in %LOCALAPPDATA%\PokemonPrivate\launcher\shell\last-error.txt.
* Read RELEASE-LIMITS.txt (in the program folder) for what this build is and what is not finished.
