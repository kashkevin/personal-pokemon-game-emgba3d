# Pokémon Emerald private multiplayer

This project targets a private adventure for one to four players total using Emerald as its foundation, with independent exploration and saves, Gen 1–6 Pokémon, Gen 6 mechanics including Fairy, 18 starters, and all eligible officially released Mega Evolutions, including later additions.

Current development checkpoint: **four actual clients, full-six 2v2 battles, native Players/team/challenge menus, durable completed battle history, recoverable paired trades, and a Windows Host/Join launcher.** The updated Windows runtime has completed a real native checkpoint and fresh Continue with a six-Pokémon character. These are separate scoped proofs; the game is not yet a friend-ready multiplayer release. [Four-client evidence](docs/four-player-foundation.md), [trade evidence and limits](docs/trade-foundation.md), [Players menu](docs/native-players-menu.md), [Windows launcher](docs/windows-launcher-gui.md).
