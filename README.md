# Pokémon Emerald private multiplayer

This project targets a private adventure for one to four players total using Emerald as its foundation, with independent exploration and saves, Gen 1–6 Pokémon, Gen 6 mechanics including Fairy, 18 starters, and all eligible officially released Mega Evolutions, including later additions.

Current checkpoint: **verified Pokémon ownership, two-player movement, and live save/recovery.** Each enrolled Pokémon now carries a persistent world-scoped ID, backed by an atomic server ledger. Two actual Emerald cores passed 22 checks covering ordinary deposit, box movement, withdrawal, capture after a normal Save, release, live recovery, and fresh Continue while the other player remained independent. Windows GUI/LAN delivery, four actual game clients, and cross-player trade transactions remain ahead. [Ownership evidence and limits](docs/phase3-ownership.md), [movement evidence](docs/phase2-presence.md), [durable storage](docs/phase3-checkpoints.md), [live checkpoint foundation](docs/phase3-live-checkpoints.md).

The Python suite passes 230 tests without skips on both Windows and WSL. The final ownership ROM passes 5,429 engine tests; the baseline's 18 known failures, 421 TODOs, and 9 expected failures remain unchanged.

Read [the master specification](docs/master-spec.md) for accepted gameplay, [the current delivery roadmap](docs/development-roadmap.md) for the owner's latest priority order, [the technical foundation](docs/technical-foundation.md) for architecture, and [the Gen 6 audit](docs/gen6-foundation-update.md) for ruleset requirements and Mega adaptations. The next sequence is safe trading → battles/teams → four-player proof → local encounter Soft Reset → automatic saves/disconnect handling → Windows Host/Join → Wi-Fi/Internet polish. Existing content requirements remain in scope.

The [combined amendment](docs/project-update-customization-friendship-shiny-charm.txt) adds synchronized Trainer customization, research/reuse before major systems, pair-specific friendship and Lucky trading, and a personal Shiny Charm with guaranteed Game Corner redemption. These are specified future features; [reuse research and customization architecture](docs/customization-and-reuse.md) guide their implementation after the required multiplayer foundations. Original briefs and all amendments remain preserved verbatim.

The requested delivery is a downloadable Windows game with **Host Game / Join Game**, for four players total including the host. The owner's PC hosts over home Wi-Fi, with direct Internet connections through port forwarding. Friends should need no compiler, Python installation, VPN, or manual emulator script setup. [Local PC setup](docs/local-pc-setup.md) records the packaging target, hosting setup, and development downloads. The player package remains future work; the current server is a development presence and checkpoint prototype.

The baseline is RHH `pokeemerald-expansion` at `expansion/1.17.1`, commit `bb1093a7c72d3961d9a37d8e02ad2abc2c866682`, built in Ubuntu 24.04 under WSL2. The [build record](docs/baseline-build.md) records versions, artifacts, and acceptance status; the [dependency ledger](docs/dependency-ledger.md) records provenance. The Lua bridge, companion, allocated ROM mailboxes, remote-avatar adapter, durable storage, explicit live checkpoints, and ownership foundation are implemented. Safe cross-player trade transactions are the next Phase 3 step.

Development must preserve small commits, repeatable tests, and known-good checkpoints. `RESEARCH_FOUNDATION_V1` records documentation only. The engine's `BASELINE_BUILD` preserves the accepted unchanged source, `MULTIPLAYER_POC` records local movement, and `DURABLE_CHECKPOINT_POC` records closed-game save recovery. `LIVE_CHECKPOINT_POC` records live save/recovery, and `OWNERSHIP_FOUNDATION_POC` records the verified ownership slice in both repositories. Private build artifacts and save evidence remain archived.

ROMs, player saves, server databases, and private backups are excluded from Git. No ROM download or distribution is part of this repository.
